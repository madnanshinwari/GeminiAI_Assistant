# 🤖 GeminiAI_Assistant – AI Chatbot  

GeminiAI_Assistant is an AI-powered chatbot built using **Google Gemini API** and **Streamlit**, designed to generate intelligent, real-time responses through a clean and interactive user interface. This project demonstrates the practical implementation of **Generative AI concepts** in a real-world application.

---

## 🚀 Features

- 🔮 Real-time AI-generated responses using Google Gemini
- 🔐 Secure API key integration
- 🧠 Intelligent conversational capabilities
- 🎨 Interactive and user-friendly Streamlit UI
- ⚡ Fast, lightweight, and easy to deploy

---

## 🛠️ Technologies Used

- **Python**
- **Google Gemini API**
- **Streamlit**
- **Generative AI**
